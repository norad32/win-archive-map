# Win Archive Map

Interactive map viewer for the [Bildarchiv Winterthur](https://bilddatenbank.winterthur.ch) image archive.

**[View Live](https://norad32.github.io/win-archive-map/)**

## Quick start

```bash
npm install
npm run dev
```

Visit [http://localhost:8000](http://localhost:8000)
