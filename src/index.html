About Win Archive Map

What is Win Archive Map?

Win Archive Map is an interactive map viewer for the Bildarchiv Winterthur .

It lets you:

  • Browse image archive entries in their geographical context
  • Filter results by title, street, district, and date range

Data Source

Image metadata (address, year, title) is sourced from the Bildarchiv Winterthur .

Built With

Bildarchiv Winterthur

Metadata source

geo.admin.ch

Swiss federal geospatial API used for address geocoding.

OpenStreetMap

Free, editable map data used as the base layer.

Leaflet

Open-source JavaScript library for interactive maps.

Leaflet.markercluster

Marker clustering plugin for organizing large point datasets.

Playwright

Browser automation for scraping dynamic web pages and fetching archive detail pages.

BeautifulSoup4

HTML/XML parsing library for extracting address metadata from archive pages.

Technical Stack

  • Frontend: HTML, CSS, JavaScript
  • Mapping: Leaflet, Leaflet.markercluster
  • Backend: Python (Playwright, BeautifulSoup, httpx)
  • Geocoding: geo.admin.ch REST API
  • Data Format: GeoJSON
